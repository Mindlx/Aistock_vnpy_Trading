# WeCom (企业微信) 推送内容类型完整清单

> 基于代码 `src/notification.py`、`src/core/pipeline_notification.py`、`src/notification_sender/wechat_sender.py`、`src/services/realtime_monitor.py`、`src/services/event_monitor.py` 分析。
> 渠道编码: `NotificationChannel.WECHAT` / 路由类型: `"wechat"`

---

## 总览

| # | 推送类型 | route_type | 推送时机 | 频率 |
|---|---------|-----------|---------|------|
| 1 | 个股精简报告 | `report` | 单股分析完成即推 (--single-notify) | 每分析完一只推一次 |
| 2 | 聚合仪表盘（完整版） | `report` | 全部股票分析完成，批量推送 | 每日 1 次 (定时 18:00) |
| 3 | 聚合仪表盘（企业微信精简版） | `report` | 同上，企业微信专用 | 每日 1 次 |
| 4 | 聚合简洁报告 (Brief) | `report` | `--brief` 模式或 BRIEF 报告类型 | 每日 1 次 |
| 5 | 大盘复盘 | `report` | 大盘复盘分析完成后 | 每日 1 次 |
| 6 | 盘中简报 (Phase 1) | `briefing` | 盘中每 15 分钟 | 每 15 分钟 |
| 7 | ATR 止损预警 (Phase 2) | `alert` | 实时价格跌破 ATR 止损位 | 触发时推送 |
| 8 | 量价异动预警 (Phase 3) | `alert` | 量比/换手率/涨跌幅异常 | 触发时推送 |
| 9 | 均线突破/跌破预警 (Phase 3) | `alert` | 价格穿越 MA5/MA10/MA20 | 触发时推送 |
| 10 | 事件驱动分析报告 | `alert` | 高重要性公司公告/互动问答 | 事件发生时 |
| 11 | 事件简报 | `alert` | 中等重要性事件 | 事件发生时 |

## 1. 个股精简报告 (Single Stock Report)

**触发条件**: `--single-notify` 运行模式，每分析完一只股票立即推送（而非等全部完成再聚合）。

**推送频率**: 每分析完一只股票推送一次。

**内容模板** (`generate_single_stock_report`):

```
## {signal_emoji} {股票名称}({股票代码})

> {报告日期} | 评分: **{sentiment_score}** | {趋势预测}

> {量化摘要: 因子 · 知识 · 状态}

{市场快照数据}

📌 **{核心决策一句话}**

📰 舆情信息
💭 舆情情绪: {sentiment_summary}
📊 业绩预期: {earnings_outlook}
🚨 风险警报:
   • {risk_1}
   • {risk_2}
✨ 利好催化:
   • {catalyst_1}
📢 最新消息: {latest_news}

📌 核心结论
**{signal_emoji} {signal_text}** | {trend_prediction}
> **一句话**: {one_sentence}
⏰ **时效性**: {time_sensitivity}

📋 操作建议: {operation_advice}
🎯 理想建仓: ¥{ideal_buy}
🛑 止损位: ¥{stop_loss}
🎊 目标位: ¥{take_profit}
🆕 空仓策略: {no_position_advice}

🧾 不通过检查项:
   ❌ {failed_check_1}

*{时间戳}* | 模型: {model_name}
```

**示例文本**:

## 6. 盘中简报 (Intraday Briefing)

**触发条件**: `--realtime-monitor` 或 `--realtime-monitor-daemon` 模式运行中，每 15 分钟自动推送一份所有监控股票的速报。

**推送频率**: 每 15 分钟一次（交易日盘中）。

**route_type**: `briefing`

**内容模板** (`_build_briefing_text`):

```
📊{时间}盘中速报

{股票名}({代码}) | ¥{price} {change_pct} | ¥{low}~¥{high} | 量比{vol} | >MA5 >MA10 | 止损 ¥{stop} | 走势预判{方向箭头}{状态}{展望}
...
```

**行情状态分类**:
| 状态 | 条件 | 展望 |
|------|------|------|
| 止损警戒 | 价格距 2×ATR 止损 < 3% | 关注止损 |
| 加速下行 | <MA5 且跌幅>1.5% 且量比>1.2 | 回避等企稳 |
| 明显走弱 | <MA5 且跌幅>1.0% | 不宜抄底 |
| 弱势震荡 | <MA5 | 缩量磨底/弱势整理 |
| 强势拉升 | >MA5>MA10 且涨幅>1.5% 且量比>1.2 | 持有观察 |
| 温和上行 | >MA5>MA10 且涨幅>1.0% | 趋势偏多 |
| 高位盘整 | >MA5>MA10 | 窄幅整理等方向 |
| 短线争夺 | >MA5但<MA10 | 放量中/缩量整理 |
| 回踩企稳 | <MA5但>MA10 | 回踩获支撑反弹 |
| 震荡观望 | 其他 | (空) |

**示例文本**:
```
📊14:30盘中速报
茅台(600519) | ¥1682.50 +1.2% | ¥1678~¥1685 | 量比1.5 | >MA5 >MA10 | 止损 ¥1620.00 | 走势预判↗温和上行趋势偏多
宁德时代(300750) | ¥198.30 -2.1% | ¥197~¥200 | 量比0.4 | <MA5 <MA10 | 止损 ¥185.00 | 走势预判↘明显走弱不宜抄底
```

## 7. ATR 止损预警 (Stop-Loss Alert)

**触发条件**: 盘中实时价格跌破 2× / 2.5× / 3× ATR 止损位。

**推送频率**: 触发时推送，冷却期内不重复（默认 `atr_cooldown` 秒可配置）。

**route_type**: `alert`

**内容模板** (`_build_atr_alert_text`):

```
🚨{时间} {股票名}({代码}) ¥{price} 跌破{multiplier}×ATR ¥{stop_price} | 支撑 {support} | 压力 {resistance} | {position_label}
```

**止损三级**:
| 级别 | 倍数 | 含义 |
|------|------|------|
| 轻度 | 2.0×ATR | 正常止损线 |
| 中度 | 2.5×ATR | 加大止损线 |
| 重度 | 3.0×ATR | 极限止损线 |

**示例文本**:
```
🚨14:35 茅台(600519) ¥1618.50 跌破2.0×ATR ¥1620.00 | 支撑 ¥1600(VWAP) | 减仓
```

## 8. 量价异动预警 (Volume-Price Alert)

**触发条件**: 盘中出现以下三种异常之一：
- **放量拉升**: 量比 > 阈值（默认 2.0）且涨幅 > 阈值（默认 1.5%）
- **缩量下跌**: 量比 < 0.3 且跌幅 < -阈值
- **换手率异常**: 换手率 > 10%

**推送频率**: 触发时推送，冷却期内不重复（默认 `volume_cooldown` 秒）。

**route_type**: `alert`

**内容模板** (`_build_volume_alert_text`):

```
{emoji}{时间}异动预警 | {股票名}({代码})
价格 ¥{price} ({change:+.1f}%) 量比 {vol:.2f} 换手率 {turnover:.1f}% | {操盘建议} | 止损 ¥{stop}
```

**类型对照**:
| 类型 | emoji | 操盘建议 |
|------|-------|---------|
| 放量拉升 | 🔥 | 主力介入 |
| 缩量下跌 | 💤 | 观望为主 |
| 换手率异常 | ⚡ | 波动加剧 |

**示例文本**:
```
🔥14:35异动预警 | 茅台(600519)
价格 ¥1695.00 (+3.2%) 量比 2.50 换手率 1.8% | 主力介入 | 止损 ¥1620.00
```

## 9. 均线突破/跌破预警 (MA Cross Alert)

**触发条件**: 盘中价格穿越 MA5 / MA10 / MA20 均线。

**推送频率**: 触发时推送，带同方向 10 分钟冷却 + 方向变化 5 分钟全局冷却。

**route_type**: `alert`

**内容模板** (`_build_ma_cross_alert_text`):

```
{emoji}{时间}均线{cross_type} | {股票名}({代码})
价格 ¥{price} {cross_type}{ma_period}(¥{ma_value}) | {操盘建议} | 止损 ¥{stop}
```

**突破/跌破操盘建议**:
| 组合 | 操盘建议 |
|------|---------|
| 跌破 MA5 | 短线转弱 |
| 跌破 MA10 | 趋势走弱 |
| 跌破 MA20 | 中期破位 |
| 突破 MA5 | 短线企稳 |
| 突破 MA10 | 趋势回暖 |
| 突破 MA20 | 中期走强 |

**示例文本**:
```
📉14:35均线跌破 | 茅台(600519)
价格 ¥1620.00 跌破MA20(¥1635.50) | 中期破位 | 止损 ¥1600.00
```

## 10. 事件驱动分析报告 (Event-Driven Reanalysis)

**触发条件**: `--event-monitor` 或 `--event-monitor-daemon` 运行时，检测到高重要性事件（重要性 ≥ 7/10，如重大公告、业绩披露、监管处罚等），自动触发对相关股票的重新分析。

**推送频率**: 事件发生时推送。

**route_type**: `alert`

**内容模板** (from `create_event_monitor`):

高重要性 → 触发 `pipeline.analyze_stock` 重新分析，推送完整分析结果：
```
🔔 *事件驱动分析* [{股票名称}]({股票代码})

{operation_advice}

{analysis_summary}
```

如果 pipeline 不可用：
```
⚠️ *高重要性事件*
股票: {code}
请手动运行分析
```

## 技术规范

### 消息格式
- **默认**: Markdown (`msgtype: "markdown"`)，最大 **4096 字节**
- **可选**: 纯文本 (`msgtype: "text"`，通过 `WECHAT_MSG_TYPE=text` 切换)，最大 **2048 字节**
- **图片模式**: 通过 `MARKDOWN_TO_IMAGE_CHANNELS` 配置（包含 `wechat` 时启用），将 Markdown 渲染为图片发送，上限 ~2MB

### 超长内容处理
- Markdown 消息默认 `wechat_max_bytes=4000`
- 超长时自动按 `---` 或 `###` 标记智能分割，添加 `(第 1/N 页)` 标记分批发送
- 非 markdown 模式上限 2000 字节

### 路由控制
所有推送类型均受 `NOTIFICATION_REPORT_CHANNELS` / `NOTIFICATION_ALERT_CHANNELS` 环境变量控制，可以指定推送类型走哪些渠道（如只让 alert 走企业微信，report 不走）。
