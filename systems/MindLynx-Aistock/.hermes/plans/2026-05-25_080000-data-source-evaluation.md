# 数据源评估研究计划

## 研究目标
对系统当前所有数据源进行多维评估，明确各源的能力边界，给出最优优先级配置建议。

## 评估维度
| 维度 | 方法 |
|:-----|:-----|
| 接口速度 | 实测请求延迟（min/avg/P95） |
| 稳定性 | 连续请求错误率、限流/封IP风险 |
| 数据质量 | 完整度、一致性（跨源交叉验证） |
| 数据清洁度 | 是否需要额外清洗（null/乱码/噪音） |
| 覆盖率 | A股全量、历史深度、实时性 |
| 易用性 | API复杂度、文档、维护成本 |
| 依赖风险 | 上游变更、许可证、付费墙 |

## 研究源
1. TuShare — 当前日K线、财务数据主源
2. EastMoney（akshare）— 新闻、K线备选
3. EastMoney（直连fetcher）— data_provider/eastmoney_fetcher.py
4. cninfo — 公告主源
5. EastMoney push2 WebSocket — 实时行情
6. SearXNG — 新闻搜索（回落源）
7. TickFlow — 市场复盘增强

## 分阶段执行
1. 数据管道架构审计 → 搞清楚当前每个数据类型的真实数据流
2. 基准测试 → 速度/稳定性/质量实测
3. 交叉验证 → 同数据跨源对比
4. 评估报告 → 按数据类型给出源优先级建议
