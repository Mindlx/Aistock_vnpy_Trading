## 二、各子系统数据链

### LY 系统（量化信号）
```
Sina HTTP → fetch_daily_bars() → parquet缓存 → RandomForest预测 → ly_signal.json
Tushare (备用) → 数据仓库缓存 (可选路径)
```

### ML 系统（AI分析）
```
首选:  pytdx(TCP) → Tushare → Baostock → EM(末位)
行情:  Tencent(实时) → Sina(实时) → akshare_em
财务:  Tushare(已配Token) → Baostock TCP → akshare_em(末位)
新闻:  EM(盘前缓存) → CNINFO巨潮(公告)
资金流: Tushare → EM(盘前缓存)
```

### AT 系统（多智能体辩论）
```
OHLCV:  akshare(EM) → pytdx(TCP) → baostock
财务:   akshare(EM) → 同花顺(ths)
三表:   同花顺(ths,非EM)
资金流: akshare(EM)独有
新闻:   akshare(EM) → stock_info_news
```

## 三、数据链路质量指标

| 维度 | 衡量方式 | 当前状态 |
|------|---------|---------|
| OHLCV 覆盖率 | 数据仓库 OHLCV 行数 | 3,738 行 ✅ |
| EM 请求量 | 每日 EM 调用次数 | ~12 次（优化后）✅ |
| 缓存命中率 | 读请求走缓存的比率 | 需统计 |
| 数据新鲜度 | 各数据 TTL 是否遵守 | 24h TTL 运行中 |
| 备份链路可达性 | 首选源失败后降级成功率 | pytdx→Sina→EM 已验证 |
