# 融合算法详解

## 概述

融合算法接收三路信号，输出一个最终决策。核心流程：
**归一化 → 分歧检测 → 缺失处理 → 加权积分 → 决策映射**

## 1. 信号归一化

三系统的输出坐标系各不相同，归一化将其映射到统一 [-1, +1] 区间。

### 1.1 lynx_vnpy 映射

| 原始信号 | prob_up 范围 | 基础观点值 | 最终得分 |
|---------|-------------|-----------|---------|
| 🟢 买入 | ≥ 65% | +0.8 | +0.8 × (prob_up/100) |
| 🟢 关注 | 55-64% | +0.8 | +0.8 × (prob_up/100) |
| ⚪ 观望 | 45-54% | 0.0 | 0.0（不乘置信度） |
| 🟡 谨慎 | 35-44% | -0.3 | -0.3 × (prob_up/100) |
| 🔴 回避 | < 35% | -0.8 | -0.8 × (prob_up/100) |

置信度低于 35% 时信号视为无效。

## 2. 分歧检测

融合引擎中最关键的创新点。

```python
def _detect_disagreement(lynx, mindlynx, tradingagent):
    scores = [有效系统的得分]
    has_bullish = any(s > 0.1 for s in scores)
    has_bearish = any(s < -0.1 for s in scores)
    disagreement = has_bullish and has_bearish

    if disagreement:
        mean = mean(scores)
        std = sqrt(mean((s - mean)^2))
        penalty = min(0.6, max(0, (std - 0.1) * 0.85))
    else:
        penalty = 0

    return disagreement, penalty
```

**设计理由**: 两个系统强烈冲突（如 +0.9 看多 vs -0.8 看空）不应得出"中性"结论，而应标记为"高不确定性，减仓"。

## 3. 缺失数据处理

当一个系统数据不可用时（如 lynx 置信度过低），权重自动重分配：

```python
# 示例：TradingAgent 缺失
lynx 权重 = 0.35 / (0.35 + 0.35) = 0.5
Mind 权重 = 0.35 / (0.35 + 0.35) = 0.5

# 只有一个系统可用时，仓位上限减半
```

## 4. 加权积分

```
融合分 = lynx_得分 × lynx_权重 + Mind_得分 × Mind_权重 + TA_得分 × TA_权重
融合分 -= uncertainty_penalty
```

默认权重：
- lynx_vnpy: **0.35** — 量化模型，日频，数据驱动
- MindLynx: **0.35** — LLM推理 + 量化因子，综合性强
- TradingAgent: **0.30** — 多智能体辩论，决策周期较长

权重在 `config/settings.yaml` 中可配置，支持动态调整（如基于历史 Sharpe 比率）。

## 5. 决策映射

| 融合分范围 | 信号 | 仓位建议 | 触发条件 |
|-----------|------|---------|---------|
| > 0.50 | 🟢 强烈看多 | 2-3成 | 三系统明确看多共识 |
| 0.20 ~ 0.50 | 🟢 弱看多 | 0.5-1成 | 两系统偏多 |
| -0.10 ~ 0.20 | ⚪ 中性/观望 | 0成 | 分歧或不清晰 |
| -0.50 ~ -0.10 | 🔴 弱看空 | 减仓至0.5成以内 | 偏空信号 |
| < -0.50 | 🔴 强烈看空 | 清仓 | 三系统共识看空 |

分歧状态下仓位上限强制降至 **1成**。
