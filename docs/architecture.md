## 层次说明

### 数据层 (systems/)

三个独立的子系统，各自有完整的数据获取和分析逻辑：

- **lynx_vnpy**: 通过新浪财经 API 获取日K线 → 计算15个技术指标 → RandomForest预测
- **MindLynx-Aistock**: 通过 akshare/efinance 等多数据源获取行情 → 12因子计算 → 15策略匹配 → LLM综合判决
- **mind_TradingAgent**: 通过 yfinance 获取数据 → 4个分析师并行分析 → 多空辩论 → 风险讨论 → 最终决策

### 适配层 (src/data_loader.py)

零侵入读取三个系统的输出。不调用任何系统的 `main()`/`run()`，只：
- lynx: `import lynx_signal` 后调用其导出函数
- MindLynx: 读取 `reports/` 下的 Markdown 报告
- TradingAgent: 读取 `~/.mind_tradingagent/logs/` 下的 JSON 日志

### 归一化层 (src/normalizer.py)

将三个系统各自的信号体系映射到统一坐标系 [-1, +1]：

| 系统 | 原始信号 | 观点值 | 调制方式 |
|------|---------|--------|---------|
| lynx | 买入/关注/观望/谨慎/回避 | +0.8/0/-0.3/-0.8 | × (prob_up/100) |
| MindLynx | 持有(≥60分)/持有(50-59)/观望/卖出 | +0.6/+0.3/0/-0.6 | 评分区间细化 |
| TradingAgent | Buy/Overweight/Hold/Underweight/Sell | +0.9/+0.5/0/-0.5/-0.9 | 固定值 |

### 融合层 (src/fusion_engine.py)

核心创新点：

1. **分歧检测**: 至少一个系统看多 AND 至少一个系统看空 → 分歧标记
2. **不确定性惩罚**: 分歧程度（信号标准差）线性映射到 0-0.6 的扣分
3. **仓位硬上限**: 分歧状态下最大仓位不超过 1成
4. **缺失容错**: 任一系统无效，权重按比例分配给剩余系统
5. **置信度调制**: lynx 的 prob_up 直接参与加权计算

### 输出层 (wecom_notifier.py + logger.py)

- **企业微信**: Markdown 格式推送，按信号强度分组展示
- **CSV**: 每日融合历史，用于后续回测分析
- **JSON**: 完整结果，可被其他系统消费
