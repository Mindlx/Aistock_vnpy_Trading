## 一、Emoji 使用规范

### 1.1 信号方向 Emoji（统一使用方向符号，避免颜色歧义）

所有子系统统一使用方向/语义符号，避免 🟢/🔴 在两套引擎中含义相反的问题：

| L7 级别 | 方向符号 | 含义 |
|---------|---------|------|
| strong_bullish | 🚀 | 强烈看多 |
| bullish | 📈 | 看多 |
| cautious_bullish | ↗️ | 谨慎看多 |
| neutral | ➡️ | 中性/持有 |
| cautious_bearish | ↘️ | 谨慎看空 |
| bearish | 📉 | 看空 |
| strong_bearish | 🚨 | 强烈看空/清仓 |

```python
# normalizer.py — 所有系统从这里引用
L7_EMOJI = {
    "strong_bullish": "🚀", "bullish": "📈", "cautious_bullish": "↗️",
    "neutral": "➡️",
    "cautious_bearish": "↘️", "bearish": "📉", "strong_bearish": "🚨",
}
```

### 1.2 分组图标（用于推送分组标题）

| 分组 | 图标 | 用途 |
|------|------|------|
| 强烈看多 | 🚀 | 高风险高收益 |
| 看多/谨慎看多 | 📈 | 正向信号 |
| 中性/持有 | 🗂 | 观望 |
| 谨慎看空/看空 | 📉 | 负向信号 |
| 强烈看空 | 🚨 | 清仓/风险 |

### 1.4 固定 Emoji 总表

| Emoji | 用途 | 引擎 | 说明 |
|-------|------|:----:|------|
| 🛟 | 融合决策/准实时速报 | Fusion |
| 🧬 | 量化信号 | LY |
| 👾 | 整点分析/盘中速报/分析报告 | ML |
| 📰 | 每日要闻/周末要闻 | ML |
| 🎯 | 大盘复盘 | ML | 文字摘要+PDF文件 |

## 二、各推送类型格式

### 2.1 融合决策（`WeComNotifier.format_daily_summary` 19:00）

每只股票一行，精简易读：

```
🛟 16:30 融合决策

📊看好3｜中立4｜看空3

🚀强烈看多 (2)
**中航机载**¥45.80 +3.21%｜ly+2.50 ml+1.80 at+2.10｜25%

📈看多 (1)
**蓝天燃气**¥12.30 +0.50%｜ly+1.20 ml+0.80 at+0.50｜15%

🗂中性/持有 (4)
**皖新传媒**¥11.08 +0.45%｜ly+0.07 ml+0.00 at-1.13｜持有

📉谨慎看空/看空 (3)
**美迪西**¥35.20 -1.50%｜ly-1.20 ml-0.80 at-1.50｜2.5%

⚠️无信号 (2)
- 000999: 所有系统均无效，无法生成信号

📡ly9/12｜ml8/12｜at7/12
```

分组顺序：🚀强烈看多→📈看多/谨慎看多→🗂中性→📉谨慎看空/看空→🚨强烈看空。
组内按融合得分降序排列。分歧股票在组内最后展示。
底部为子系统可用性（有数据/总股票数）。

### 2.2 准实时速报（`RealtimeFusion` 09:33+，每5分钟）

```
🛟 14:05 融合速报

📈 **中航机载** +2.35%｜ly+1.50 ml+1.20 at+0.80｜25%
📉 **美迪西** -1.20%｜ly-0.80 ml-0.50 at-1.50｜2.5%
```

仅当融合得分变化超过阈值时推送，无变化不推送。

### 2.4 ML 整点分析（`generate_wechat_dashboard` 11:00/14:00）

每只股票完整信息，含核心判断、情报、预期价位、操盘建议：

```
👾 11:00 整点分析｜共12
🔴买5 🟡持3 🟢卖4

🚀 **中航机载**｜强烈看多
📈¥45.80 +3.21%｜量比1.5
📌核心判断：军工重组预期升温，均线多头排列，量价配合良好
🥇业绩预期：子公司中标金额同比增长35%
📱舆情情绪：市场情绪偏积极，机构研报多为增持评级
🚨风险警报：板块估值处于近3年高位｜基金持仓连续2个季度下降
⭐正向催化：大股东增持完成｜MACD金叉
🎯预期价位：理想买入¥44.50｜止损¥43.00｜目标¥48.00｜空仓者轻仓试探｜持仓者继续持有
🪄操盘建议：建仓44.50，止损43.00，目标48.00
⚡未通过项：量比低于1.0｜MACD顶背离

📈 **美迪西**｜看空
📉¥35.20 -1.50%｜量比0.8
📌核心判断：医药板块整体承压，量价背离短期不宜抄底
🚨风险警报：子公司业绩预减｜股价跌破MA20
🎯预期价位：止损¥34.50｜目标¥36.00
🪄操盘建议：偏空，不操作

📡来源：ml12因子+LLM分析
```

字段说明：
| 字段 | 来源 | 条件 |
|------|------|------|
| 📌核心判断 | `core_conclusion.one_sentence` | 必有 |
| 🥇业绩预期 | `intelligence.earnings_outlook` | 有时 |
| 📱舆情情绪 | `intelligence.sentiment_summary` | 有时 |
| 🚨风险警报 | `intelligence.risk_alerts` | 最多2条 |
| ⭐正向催化 | `intelligence.positive_catalysts` | 最多2条 |
| 🎯预期价位 | `battle.sniper_points` + `position_advice` | 必有 |
| 🪄操盘建议 | 基于 score + sniper 自动生成 | 必有 |
| ⚡未通过项 | `battle.action_checklist` | 有❌/⚠️时 |

### 2.5 每日情报/周末情报（`_push_highlights` 09:00/周日20:00）

按股票分组，含可点击链接和情感标签。实际内容比示例丰富——每条新闻可含正文 snippet（最长600字符），后续注入 LLM：

```
📰 09:00 每日要闻 | 盘前

**中航机载**
[大股东增持完成-利好](https://...) [利好]

**市场情报**
[隔夜美股三大指数集体收涨](https://...)
> 美联储主席表态偏鸽，市场预期9月降息概率升至65%
美股科技股领涨，纳斯达克涨幅超1.5%，中概股普遍走强……

**平潭发展**
海南自贸区政策利好 [利好]

📊12条 | 下个交易时段自动注入LLM
```

重点特性：
- **重要性≥8** 的新闻自动标注 `[利好]`/`[利空]`
- **市场情报**（`code="__market__"`）嵌入 snippet 正文，最长600字符，注入LLM分析上下文
- 标题过长自动截断（45字符），html 标签自动清理
- 股票名加粗，不展示代码
- 公告类（`source="公告"`）无 URL 链接

## 三、消息分组规则

### 3.1 融合决策分组

按 L7 信号分为 5 组（从 `GROUP_ICONS`）：
1. 🚀 强烈看多
2. 📈 看多/谨慎看多
3. 🗂 中性/持有
4. 📉 谨慎看空/看空
5. 🚨 强烈看空

组内按融合得分降序排列。Top 3 在组名前标注统计数。

### 3.2 分歧股票

当三个子系统方向冲突时（`has_disagreement=True`），该股票在组内最后展示，受仓位上限为 1 成。

## 五、推送格式限制

| 限制项 | 值 | 应对策略 |
|--------|----|---------|
| 企业微信 Markdown 长度 | ~4096 字节 | ML 分析超长自动分批; Fusion 控制单条不超限 |
| 表格渲染 | 移动端列对齐不稳定 | 大盘复盘用 PDF 替代文字表格 |
| 图片 | 不支持 Markdown 内嵌 | 图片只能以文件形式发送(大盘复盘/评级PDF) |
| 字体颜色 | 不支持 | 统一依赖 emoji 区分信号 |
| 重试 | 3次指数退避(1.5s/3s/6s) | 网络抖动时自动恢复(WeComNotifier/WechatSender) |
| 速率限制 | 18次/min | 滑动窗口限流(WechatSender) |
