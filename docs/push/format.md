## 一、Emoji 使用规范

### 1.1 信号方向 Emoji（统一使用方向符号，避免颜色歧义）

所有子系统统一使用方向/语义符号，避免 🟢/🔴 在两套引擎中含义相反的问题：

| L7 级别 | 方向符号 | 含义 |
|---------|---------|------|
| strong_bullish | 🚀 | 强烈看多 |
| bullish | 📈 | 看多 |
| cautious_bullish | ↗️ | 谨慎看多 |
| neutral | ➡️ | 中性/持有 |
| cautious_bearish | ↘️ | 谨慎看空 |
| bearish | 📉 | 看空 |
| strong_bearish | 🚨 | 强烈看空/清仓 |

```python
# normalizer.py — 所有系统从这里引用
L7_EMOJI = {
    "strong_bullish": "🚀", "bullish": "📈", "cautious_bullish": "↗️",
    "neutral": "➡️",
    "cautious_bearish": "↘️", "bearish": "📉", "strong_bearish": "🚨",
}
```

### 1.2 分组图标（用于推送分组标题）

| 分组 | 图标 | 用途 |
|------|------|------|
| 强烈看多 | 🚀 | 高风险高收益 |
| 看多/谨慎看多 | 📈 | 正向信号 |
| 中性/持有 | 🗂 | 观望 |
| 谨慎看空/看空 | 📉 | 负向信号 |
| 强烈看空 | 🚨 | 清仓/风险 |

### 1.3 其他固定 Emoji

| Emoji | 用途 | 所属 |
|-------|------|------|
| 🛟lma | 融合决策/准实时速报 | Fusion |
| 🧬ly | 量化信号 | LY |
| 👾ml | 个股分析/盘中速报 | ML |
| 🎯ml | 大盘复盘 | ML |
| 📰ml | 每日要闻/周末要闻 | ML |
| 🚨ml | 盘中告警(ATR止损) | ML |
| 🐉 | 龙虎榜(已合入融合决策) | Fusion |
| 💰 | 评级报告/东方财富 | ML |

## 二、个股行格式

### 2.1 融合决策/准实时（WeComNotifier）(v4.1 精简版)

```
**{股票名称}**｜¥{价格} {涨跌幅}｜ly{得分} ml{得分} at{得分}｜仓位{比例}
```

示例：
```
**中航机载**｜¥11.08 +0.45%｜ly+0.07 ml+0.00 at-1.13｜仓位持有
```

### 2.2 量化信号（WeComNotifier via LY）

```
{emoji}**{股票名称}**｜L7{score}｜置信{prob_up}%｜{RSI}｜{MACD}｜{ATR}｜{label}
```

### 2.3 ML 整点分析/盘中报告（`generate_wechat_dashboard`）(v4.1)

完整格式，每只股票包含核心结论+作战计划+情报：

```
👾ml 10:30 盘中报告
共12｜🟢买5 🟡持3 🔴卖4

📈 **中航机载**｜强烈看多
¥45.80 +3.21%｜量比 1.5
🔥 **核心结论**: 军工板块重组预期升温，均线多头排列，量价配合良好
🎯 **作战计划**: 狙击点¥44.50 止损¥43.00 目标¥48.00
📊 **情报**: 大股东增持完成(利好)｜MACD 金叉｜RSI 65(中性)

📉 **美迪西**｜看空
¥35.20 -1.50%｜量比 0.8
🔥 **核心结论**: 医药板块整体承压，量价背离，短期不宜抄底
🎯 **作战计划**: 反弹至¥36.00减仓 止损¥34.50
📊 **情报**: 子公司业绩预减(利空)｜股价跌破MA20
```

其中：
- **核心结论** = 技术面+基本面+消息面的融合判断
- **作战计划** = 狙击点/止损/目标价（来自 LLM 运算）
- **情报** = 该股最新的利好/利空事件标签

### 2.4 每日情报/周末情报（`_push_highlights`）

按股票分组，含可点击链接和情感标签：

```
📰ml 每日要闻 | 盘前

• 中航机载(600372)
  [大股东增持完成](https://...) [利好]
• 市场情报
  [隔夜美股三大指数集体收涨](https://...)
  > 美联储主席表态偏鸽，市场预期9月降息概率升至65%
  美股科技股领涨，纳斯达克涨幅超1.5%，中概股普遍走强……
• 平潭发展(000592)
  [海南自贸区政策利好](https://...) [利好]

📊12条 | 下个交易时段自动注入LLM
```

重点特性：
- **重要性≥8** 的新闻自动标注 `[利好]`/`[利空]`
- **市场情报**条嵌入 snippet 正文（最长 600 字符），后续注入 LLM 分析上下文
- 股票名+代码格式：`• 股票名(代码)`
- 链接可点击，url 自动清理追踪参数

### 2.5 东方财富评级简报（`generate_brief_text`）

```
💰ml 15:30 东方财富评级

✅ **中航机载**｜86/92｜参与意愿增强,关注度提升
📈 **蓝天燃气**｜72/65｜参与意愿稳定,关注度上升
💤 **皖新传媒**｜50/48｜参与意愿一般,关注度持平
📉 **美迪西**｜35/42｜参与意愿下降,关注度回落

📎 详情见PDF报告
```

格式：`{图标} **{股票名}**｜{参与意愿}/{关注度}｜{一句话短评}`

图标含义：✅强势 📈活跃 💤平淡 📉弱势 ❌回避
后发 PDF 文件：`{date}东方财富评级报告.pdf`

## 三、消息分组规则

### 3.1 融合决策分组

按 L7 信号分为 5 组（从 GROUP_ICONS）：
1. 🚀 强烈看多
2. 📈 看多/谨慎看多
3. 🗂 中性/持有
4. 📉 谨慎看空/看空
5. 🚨 强烈看空

组内按融合得分降序排列。Top 3 在组名前标注统计数。

### 3.2 分歧股票

当三个子系统方向冲突时（`has_disagreement=True`），该股票在组内最后展示，不受限仓位上限为 1 成。

## 四、推送时间线

### 4.1 日间推送（交易日）

| 时间 | 推送内容 | 引擎 | 合并策略 |
|------|---------|------|---------|
| 08:30 | 📰ml 每日要闻 | ML | 独立 |
| **11:00** | 👾ml 整点全量分析 | ML | **独立（早盘）** |
| 11:45 | 🎯ml 大盘复盘(文字+PDF) | ML | 文字+PDF两段 |
| **14:00** | 👾ml 整点全量分析 | ML | **独立（午盘）** |
| 15:15 | 🧬ly 量化信号 | Fusion | 独立 |
| 15:45 | 🎯ml 大盘复盘(文字+PDF) | ML | 文字+PDF两段 |
| 19:00 | 🛟lma 融合决策+🐉龙虎榜 | Fusion | **已合并为一条** |
| 19:01 | 💰 评级PDF(延迟60s) | Fusion→ML | 独立，延时发送 |
| 盘中 | 🚨 止损/均线/量价告警 | ML | 事件驱动 |

### 4.2 周末推送

| 时间 | 推送内容 | 说明 |
|------|---------|------|
| 周日 20:00 | 📰 周末要闻 | 周度新闻汇总 |
| 周一 07:30 | 📰 周末情报补量 | 补充推送 |

### 4.3 融合准实时速报

每 300s 运行一次，仅当融合得分变化超过阈值时推送，不变化不推送。

## 五、推送格式限制

| 限制项 | 值 | 应对策略 |
|--------|----|---------|
| 企业微信 Markdown 长度 | ~4096 字节 | ML 分析超长自动分批; Fusion 控制单条不超限 |
| 表格渲染 | 移动端列对齐不稳定 | 大盘复盘用 PDF 替代文字表格 |
| 图片 | 不支持 Markdown 内嵌 | 图片只能以文件形式发送(大盘复盘 PDF) |
| 字体颜色 | 不支持 | 统一依赖 emoji 区分信号 |
| 重试 | 3次指数退避(1.5s/3s/6s) | 网络抖动时自动恢复(WeComNotifier) |
