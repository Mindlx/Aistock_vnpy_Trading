## 一、三系统时效性能力

| 系统 | 盘中实时 | 单只耗时 | 10只批量 | 数据源 | 预测目标 |
|------|---------|---------|---------|--------|---------|
| **lynx_vnpy** | ❌ 不能 | 2-3秒 | 20-30秒 | 新浪日K线 | 次日涨跌 |
| **MindLynx RTM** | ✅ WebSocket | 15秒轮询 | 持续监控 | WebSocket+HTTP | 盘中异动/止损 |
| **MindLynx 批量** | ⚠️ API可按需 | 30-60秒 | 3-5分钟 | akshare/efinance | 综合评分 |
| **mind_TradingAgent** | ❌ 太重 | 3-6分钟 | 30-60分钟 | yfinance | 多智能体评级 |

### 关键约束

**lynx_vnpy 不能盘中的原因：**
- 数据源为新浪日K线（`scale=240`），非实时 tick
- 特征依赖完整日线（`pct_change(5/10/20)`, `rolling(14)` 等）
- 预测目标 `shift(-1)` = 次日涨跌
- 优势：极快，10只股票 20-30 秒跑完

**mind_TradingAgent 不能盘中的原因：**
- 每只股票 8-12 次 LLM 调用（4分析师+2辩论+1经理+1交易员+3风控+1PM）
- DeepSeek V4 Flash 每次 15-30 秒，单只 3-6 分钟
- 10只 = 30-60 分钟，消耗大半个交易时段
- `concurrency_limit=1` 硬编码串行

**MindLynx RTM 才是真正的盘中实时能力：**
- Phase 1: 15分钟盘中简报
- Phase 2: ATR止损（3档：2x/2.5x/3x ATR）
- Phase 3: 量价异动 + 均线突破告警
- WebSocket + 15秒 HTTP 轮询双模
- 自动跟随 A 股交易时段（09:15-11:30, 13:00-15:00）

## 二、三层次时序架构

```
盘中 (09:30-15:00)         盘后 (15:00-17:00)         隔日 (08:00)
┌─────────────────┐    ┌────────────────────┐    ┌────────────────┐
│ MindLynx RTM    │    │ 15:30 lynx_vnpy    │    │ 08:00 融合推送  │
│ ├─ ATR止损      │    │ 15:35 Mind批量     │    │ ├─ lynx信号    │
│ ├─ 量价异动     │───▶│ 15:38 快速融合     │───▶│ ├─ Mind评分    │
│ ├─ 均线突破     │    │ 16:00 TA深度论证   │    │ ├─ TA评级      │
│ └─ 15min简报    │    │ 17:00 最终融合     │    │ └─ 分歧/共识   │
└─────────────────┘    └────────────────────┘    └────────────────┘
        盘中预警                   日终信号                      行动参考
```

### 三个时间层次

| 层次 | 时间 | 内容 | 决策价值 | 推送方式 |
|------|------|------|---------|---------|
| **T1: 盘中预警** | 09:30-15:00 | ATR止损/量价异动/均线突破 | 🚨 实时风险控制 | MindLynx RTM 直接推 |
| **T2: 日终信号** | 15:30-15:40 | lynx+Mind 快速融合 | 📊 当日决策参考 | 融合引擎推 |
| **T3: 深度论证** | 16:00-17:00 | +TradingAgent 辩论 | 🔬 多智能体补充 | 融合引擎推（隔日晨报用） |

### TradingAgent 的特殊处理

由于 TA 太慢（30-60 分钟），不能阻塞日终融合：

1. **快速融合（15:38）**先出结果，不含 TA
2. TA 在后台异步跑（16:00-17:00）
3. 当日融合标记 `ta_stale=True`，使用前一次 TA 结果
4. TA 跑完后更新，供次日 08:00 晨报使用
5. 融合引擎已在 `fusion_engine.py` 中通过 `is_degraded` 标志支持缺失系统处理

## 三、推送内容设计

| 推送 | 时间 | 内容 | 格式 |
|------|------|------|------|
| **盘中预警** | 盘中实时 | ATR止损/量价异动/均线突破 | 简短告警文本 |
| **15分钟简报** | 每15分钟 | 当前持仓状态+异动 | Markdown 速报 |
| **日终融合** | ~15:40 | 三系统评分+融合分+分歧标记 | Markdown 报告 |
| **晨间简报** | 08:00 | 前日TA结果+今日融合 | Markdown 报告 |
