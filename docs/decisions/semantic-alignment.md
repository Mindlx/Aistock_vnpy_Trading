# 三系统分级粒度与语义对齐分析

> 研究问题：三个子系统的评判分级体系不同，如何科学地对齐到统一决策空间？
> 分析方法：对照各系统的原始设计意图、实际输出分布、语义参考系

---

## 1. 三个系统的参考系完全不同

| 系统 | 参考系 | 本质 | 类比 |
|------|--------|------|------|
| **ly** | **置信度** (Confidence) | "涨的概率是多少？" | 天气预报：降雨概率 70% |
| **ml** | **操作建议** (Action) | "我应该怎么做？" | 医生处方：建议服药 |
| **at** | **研究评级** (Research) | "这家公司值得投资吗？" | 分析师研报：买入评级 |

### 1.1 ly：置信度参考系

ly 的核心是 `predict_proba()` 输出的**数学概率**。信号阈值是人为加的：

```
真实信号: prob_up = 43.7%  (连续值，0-100)
离散化:    prob_up>=65% → "买入", >=55% → "关注" ...
```

**问题**: 阈值是原始开发者随意设定的。为什么 65% 是买入而不是 60%？没有理论依据。真正有价值的是 prob_up 本身。

### 1.2 ml：操作建议参考系

ml 的核心是**操作指令**，不是置信度：

| 建议 | 语义 | 对应动作 |
|------|------|---------|
| 买入 | 新开仓买入 | 从 0 仓位到有仓位 |
| 加仓 | 增加持仓 | 从已有仓位往上加 |
| 持有 | **维持现有仓位** | 不做任何操作 |
| 观望 | 继续观察 | 不入场 |
| 减仓 | 减少持仓 | 卖出部分 |
| 卖出 | 清仓 | 全部卖出 |

**"持有"不等于"弱看多"**。持有是"已有的继续持有"——这可能是浮盈持有、浮亏扛单、或者只是没到卖点。它不应被映射到正向的买入信号。

### 1.3 at：研究评级参考系

at 输出的是**分析师式评级**，来自多智能体辩论的共识：

| 评级 | 语义 |
|------|------|
| Buy | 在当前位置应该买入 |
| Overweight | 组合中应超配该股票 |
| Hold | 维持现有配置 |
| Underweight | 组合中应低配 |
| Sell | 应该卖出 |

这是最接近传统金融研究的框架。

---

## 2. 统一决策空间设计

### 2.1 不能强行 5 级——需要 7 级

```
ly 有5级 + 连续概率
ml 有6级
at 有5级

最细粒度是 ml 的 6 级 → 统一空间至少需要 7 级才能容纳所有系统的区分度
```

### 2.2 七级统一空间

```
级别        ly (置信度)          ml (操作)         at (研究)
──────────────────────────────────────────────────────────
S1 强买    prob_up ≥ 75%       买入              Buy
S2 中买    prob_up ≥ 65%       加仓              Overweight
S3 弱买    prob_up ≥ 55%       —                 —
S4 中性    prob_up 45~55%      持有 / 观望       Hold
S5 弱卖    prob_up ≥ 35%       减仓              Underweight
S6 中卖    prob_up ≥ 25%       卖出              —
S7 强卖    prob_up < 25%       —                 Sell
```

### 2.3 关键修正

| 修正点 | 当前做法 | 建议 |
|--------|---------|------|
| **持有=0.45 过高** | 将"持有"映射为弱看多 | **持有回归中性-弱看多(0.15~0.20)**: 它不是买入信号 |
| **ml 缺少弱买/中卖** | 强塞到5级框架 | **保留缺口**: ml 的 6 级只需要在 7 级空间中占用 6 个位置 |
| **at 缺少弱买/中卖** | 强塞 | **同样保留缺口**: at 的 5 级占用 7 级中的 5 个位置 |
| **ly 的 prob_up 被浪费** | 离散化为5级 | **保留连续调制**: prob_up 在各级内继续提供区分度 |

### 2.4 映射值建议

```python
# 7 级统一空间 → [-0.8, +0.8] 映射
S1_STRONG_BUY  = 0.80   # ly: prob_up>=75%,  ml: 买入,        at: Buy
S2_MOD_BUY     = 0.55   # ly: prob_up>=65%,  ml: 加仓,        at: Overweight
S3_WEAK_BUY    = 0.30   # ly: prob_up>=55%,  ml: —,           at: —
S4_NEUTRAL     = 0.00   # ly: prob_up 45-55, ml: 持有/观望,   at: Hold
S5_WEAK_SELL   = -0.30  # ly: prob_up>=35%,  ml: 减仓,        at: Underweight
S6_MOD_SELL    = -0.55  # ly: prob_up>=25%,  ml: 卖出,        at: —
S7_STRONG_SELL = -0.80  # ly: prob_up<25%,   ml: —,           at: Sell
```

**各系统的实际占用**:

| 系统 | 占用级别 | 含义 |
|------|---------|------|
| ly | 全部 7 级 (连续) | prob_up 连续分布，可在各级间自然过渡 |
| ml | **6 级** (缺 S3/WEAK_BUY) | 买入→加仓→持有/观望→减仓→卖出 |
| at | **5 级** (缺 S3/S6) | Buy→Overweight→Hold→Underweight→Sell |

### 2.5 关键语义决策

**"持有"的定位**:
- 不是中性（因为持仓者在市场中有暴露）
- 也不是弱看多（因为持有者不主动买入）
- **最佳定位: 中性偏多 (0.15~0.20)** — 反映了"还没到卖出点"但也不是买入信号

**"观望" vs "持有"**:
- 观望 = 空仓者的选择（中性，0.0）
- 持有 = 持仓者的选择（偏多，0.15~0.20）
- 两者在 ml 中同时存在，在统一空间中靠拢但不重合

---

## 3. 实施建议

| 优先级 | 改动 | 影响 |
|--------|------|------|
| P0 | 将"持有"从 0.45 降至 0.20 | ml 唯一的重大调整 |
| P1 | 将"减仓"从 -0.45 升至 -0.30 | 与 ly"谨慎"对齐 |
| P2 | 将"Underweight"从 -0.45 升至 -0.30 | 与"减仓"一致 |
| P3 | 将 prob_up 阈值从 65/55/45/35 改为 75/65/55/45/35/25 | 释放 ly 的完整 7 级潜力 |

> **后续演进 (2026-06-29)**: ml 的 `normalize_mindlynx_score` 已从语义对齐升级为精度校准映射（v4.0）。

> 但 ml 的映射方法论已从"语义对齐"升级为"精度校准"。
