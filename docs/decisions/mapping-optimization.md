## 2. 优化方案

### 2.1 设计原则

1. **语义对齐**: 各系统相同语义的信号映射到相近值（ly's 买入 ≈ ml's 买入 ≈ at's Buy）
2. **范围收敛**: at 的映射范围不应超过 ly 和 ml
3. **保留区分度**: 相同系统内不同强度的信号应有足够差距
4. **基于数据**: 映射值参考实际分布，不凭空设定

### 2.2 建议映射

#### ly（微调）

当前的 prob_up 调制机制合理，base_score 基本保持：
```
买入=0.70, 关注=0.50, 观望=0.0, 谨慎=-0.30, 回避=-0.70
```
- 买入 0.80→0.70: 与 ml 的买入对齐
- 关注 0.55→0.50: 更简洁
- 回避 -0.80→-0.70: 与买入对称

#### ml（关键修正）

```
买入=0.70, 加仓=0.60, 持有=0.50, 观望=0.0, 减仓=-0.50, 卖出=-0.70
```
- **买入 0.6→0.7**: 与 ly 的买入对齐，高于持有
- **持有 0.6→0.5**: 买入＞持有，拉开差距
- **减仓 -0.6→-0.5**: 比卖出弱一级
- **卖出 -0.6→-0.7**: 与买入对称

#### at（关键修正）

```
Buy=0.60, Overweight=0.40, Hold=0.0, Underweight=-0.40, Sell=-0.60
```
- **Buy 0.9→0.6**: 大幅压缩，与 ly/ml 的买入对齐
- **Overweight 0.5→0.4**: 与 ml 的加仓对应
- **Underweight -0.5→-0.4**: 对称
- **Sell -0.9→-0.6**: 大幅压缩，与 ly/ml 对齐

### 2.3 方案对比

| 系统 | 当前范围 | 建议范围 | 变化 |
|------|---------|---------|------|
| ly | -0.80 ~ +0.80 | -0.70 ~ +0.70 | 微调（收敛 0.1） |
| ml | -0.60 ~ +0.60 | -0.70 ~ +0.70 | 扩底（卖出加强） |
| at | **-0.90 ~ +0.90** | **-0.60 ~ +0.60** | ⚠️ 大幅压缩 |

### 2.4 预期效果

```
场景: ly 强烈看空(prob_up=20) vs at 看多(Buy)
当前: ly=-0.80×0.80=-0.64,  at=+0.90     → ly vs at 差距 1.54
建议: ly=-0.70×0.80=-0.56,  at=+0.60     → ly vs at 差距 1.16

场景: ly 看多(prob_up=70) vs ml 买入 vs at Buy
当前: ly=0.70×0.70=0.49,  ml=0.6,  at=0.9  → at 远超 ly+ml
建议: ly=0.70×0.70=0.49,  ml=0.7,  at=0.6  → ml>ly>at，更合理
```
