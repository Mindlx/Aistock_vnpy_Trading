# ML LLM Prompt 重构方案

## 现状

当前 ML LLM prompt 包含 ~50-60 个数据点，覆盖 7+ 类别：

| 类别 | 内容 | 数据量 | 是否保留 |
|------|------|:------:|:--------:|
| 因子 z-score | 12因子逐行展示 | 12 | 🔄 折叠为1行 |
| 策略规则 | 15策略逐条判断 | ~15 | 🔄 折叠为摘要 |
| LY 信号 | RF+LGB prob_up | 2-3 | ✅ 保留 |
| 东方财富评级 | 外部数据 | 1 | ✅ 保留 |
| 技术指标 | RSI/MACD/布林/CCI | ~8 | 🔄 折叠为关键值 |
| 市场背景/新闻 | 大盘/消息面 | 2-3 | ✅ 保留 |
| 知识库 | 历史分析 | 1 | ✅ 保留 |
| **融合引擎结果** | 三系统融合结果 | **0** | ✅ 从未注入 |
| **AT 结果** | TradingAgent 辩论 | **0** | ✅ 从未注入 |

## 改动范围

### analyzer.py `build_prompt()`

#### 1. 因子折叠
```python
# 当前（12行）：
| 动量反转 | +0.42σ | ↑ 动量反转 | IC=8.0% |
| 低波 | -0.31σ | ↓ 低波 | IC=6.5% |
...

# 改为（1行）：
因子综合: +0.42 (偏多) | 置信度: 中高 | 因子分歧: 动量偏多 vs 波动偏空
```

#### 2. 策略折叠
```python
# 当前（15条逐条判断条件是否满足）
# 改为：
策略面: 8/15 偏多触发 | 主力策略: 放量突破(触发) 多头趋势(触发) 缠论三买(未触发)
```

#### 3. 技术指标折叠
```python
# 当前：
RSI 52.3 | MACD +0.15 | ATR 2.3% | CCI +120 | ...
# 改为（仅3-4个）：
关键指标: RSI 52.3(中性) | MACD +0.15(偏多) | BOLL 上轨(超买警告)
```

#### 4. 新增操作建议指引
```python
# 在仪表盘要求部分新增：
- **operation_advice 与因子方向一致**：你的 operation_advice 应与因子综合方向一致。
  综合因子偏多时用"买入/加仓"，偏空时用"卖出/减仓"，中性时用"持有/观望"。
  如果你从新闻/消息面获得了因子无法捕获的关键信息可偏离此指引，
  但必须在 analysis_summary 中解释原因。
```

### 不动的部分
- LY 信号 → 保留一行概览
- 东方财富评级 → 保留（独立第三方数据）
- 知识库历史分析 → 保留（背景参考）

### 对齐的后修正
`_calibrate_operation_advice()` 已实现，作为兜底。

## 预期效果

| 指标 | 改前 | 改后 |
|:-----|:---:|:---:|
| 注入数据点 | ~50-60 | ~15-20 |
| 因子展示 | 12行z-score | 1行摘要 |
| 策略展示 | 15条逐条判断 | 2行统计 |
| 技术指标 | ~8个 | ~4个 |
| operation_advice 准确率 | 22-27% | 预期提升 |
| LLM 认知负担 | 高（矛盾信号） | 低（仲裁后输入） |

## 执行顺序

1. `analyzer.py`: 折叠因子展示 → `build_factor_profile()` 改为摘要模式
2. `pipeline.py`: 折叠策略展示 → reduce策略列表为摘要
3. `analyzer.py`: 折叠技术指标
4. `analyzer.py`: 新增操作建议方向指引
5. 编译检查 + 运行验证
