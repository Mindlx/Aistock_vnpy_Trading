### 三个未用字段深度分析

#### 主力成本

```
含义:  主力资金的加权平均持仓成本
计算:  基于东方财富对主力资金(大单/超大单)的跟踪
用途:  
  成本价 vs 现价的偏离度 = (现价 - 成本) / 成本
  现价 < 成本 → 主力被套 → 可能支撑 → 做多信号
  现价 > 成本 → 主力盈利 → 可能抛压 → 做空信号
  
自选股示例 (2026-06-24):
  昭衍新药  主力成本=38.15  现价=42.56  偏离=+11.6%  → 主力获利，注意抛压
  中航机载  主力成本=10.82  现价=11.64  偏离=+7.6%   → 主力获利
  美迪西    主力成本=66.93  现价=47.85  偏离=-28.5%  → 主力深度被套→支撑
```

**独立性判断**：LY 使用技术指标（RSI/MACD/ATR），ML 使用因子+LLM，AT 使用辩论。**主力成本完全独立于三者**，是结构化信息不对称信号。

#### 上升

```
含义:  日内主动买盘-卖盘的净差（整数，可正可负）
范围:  -2845 ~ +3687（2026-06-24）
说明:  与涨跌幅高度相关（相关系数高），但不等同
       主动买盘多但价格不动 → 可能有大单压盘
       主动卖盘多但价格不跌 → 可能有大单托盘

示例: 古麒绒材 上升=+751 涨跌幅=+0.36%  → 买盘远强于涨幅，潜在强势
       蓝天燃气 上升=-1209 涨跌幅=-4.08% → 卖盘压力与跌幅一致
```

**独立性判断**：与涨跌幅重叠度高，独立信号价值相对较低。但**残差**（上升预测涨跌幅后的剩余值）可能揭示"价格的微观结构推力"。

#### 目前排名

```
含义:  全市场 1-5206 的综合排名（1=最好）
计算:  基于综合得分排序
用途:  
  绝对排名: 头部 vs 尾部股票的截面对比
  排名变化: 今日排名 vs 昨日排名 → 市场关注度的边际变化
  
自选股示例 (2026-06-24):
  昭衍新药  排名=158   (↑4.24%)  → 全市场前 3%，表现一致
  平潭发展  排名=4599  (↓4.01%)  → 全市场后 10%，表现一致
  古麒绒材  排名=562   (↑0.36%)  → 排名高但涨幅小 → 可能被低估
```

**独立性判断**：现有子系统都不做横截面对比。LY/ML 做个股独立预测，AT 做辩论。**排名是全市场相对位置，是全新维度**。

## 二、个股时序 API
