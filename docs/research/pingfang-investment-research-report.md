# 平方和投资全面调研报告

**报告日期**：2026年7月6日
**研究对象**：宁波平方和投资管理合伙企业（有限合伙）
**研究目的**：为个人量化交易系统开发提供机构级参考框架


## 一、公司概况

### 1.1 基本信息

平方和投资成立于**2015年8月26日**，同年10月30日完成私募备案（登记编号P1025836），注册资本1000万元，实缴比例100%。总部位于北京，在上海设有办公室。

### 1.2 规模演变

公司规模呈持续增长态势：

| 时间节点 | 管理规模 | 关键事件 |
| :--- | :--- | :--- |
| 2016年 | 突破10亿元 | 成立仅一年 |
| 2018年 | 突破30亿元 | — |
| 2019年 | 突破50亿元 | — |
| 2023年 | 约65亿元 | 稳步增长 |
| 2025年10月 | **突破100亿元** | 首次跻身百亿私募 |
| 2025年 | **约150亿元** | 指数增强75亿+市场中性75亿 |

2025年10月，平方和投资与喜岳投资、上海孝庸私募等6家机构一同首次新晋百亿私募阵营。目前公司拥有**38名全职员工**，办公地点位于北京中关村。

### 1.3 行业荣誉

公司成立以来已斩获**金牛奖、金长江奖、英华奖等70余项权威荣誉**。
2025年11月，荣获中国证券报主办的"**三年期金牛量化机构（多空对冲策略）**"奖项。

### 1.4 创始人背景

**吕杰勇**（创始人、总经理、投资总监）：
- 北京大学数学学士、计算机硕士
- 曾任职腾讯（搜索事业部核心算法研究员）
- 曾任职博时基金（投资经理助理）
- 曾任职中信证券（另类投资部系统化策略经理）
- 2009年开始投身量化投资领域
- 2015年创立平方和投资

吕杰勇的创业初心是对标全球顶级量化对冲基金——**詹姆斯·西蒙斯的文艺复兴科技公司**，立志"中国要有自己的量化对冲基金"。

### 1.5 核心团队升级

2025年3月，**方壮熙**重磅加盟平方和投资，担任投资总监。
- 清华大学本科、纽约大学博士
- 曾任职世坤投资（WorldQuant）高级执行研究总监兼中国区副总经理
- 2009年起历任世坤投资高级研究员、中国区研究总监、全球研究副总监
- 深谙量化策略研发与投研管理

方壮熙的加入形成了"**总经理+投资总监**"的科学分工架构，推动因子开发模式深度整合。


## 二、投研体系与技术架构

### 2.1 五位一体的策略开发模式

平方和投资执行"**数据处理 → 因子挖掘 → 因子合成 → 投资组合优化 → 交易执行**"五位一体的策略开发模式。

这一模式与你截图中展示的流程高度吻合：数据中心为基础 → 统计挖掘与人工智能为中间层 → 各类因子输出 → 组合优化 → 算法交易。

### 2.2 因子体系（核心）

**因子覆盖**：公司早期主要依靠量价因子，随着市场演进，逐渐拓展至**基本面、分析师预期、另类数据**等维度，涵盖日内多频段预测。

**因子构成比例**：量价因子与基本面/另类因子**各占约50%**。

**因子挖掘方式**：以**人工为主（70%-80%）**，辅以机器学习。

**因子库规模**：从3500个逐步扩展至**4000-5000个**，实盘使用约**800-900个**。

**入库标准**（与你截图中的描述一致）：
- **强有效性**：因子需具备显著的预测能力
- **低相关性**：因子之间相关性低，确保信息不冗余
- **逻辑校验**：因子必须具有可解释的金融逻辑
- **10年以上历史数据测试**：样本内外验证，严控过拟合

### 2.3 模型架构

**模型类型**：采用**线性与非线性（机器学习）模型结合**，从线性模型发展到线性非线性混合模型。

**子策略数量**：超过**150个**子策略。

**预测周期**：以**中低频为主（7-10天预测周期）**。

**AI应用**：在因子挖掘、信号预测、组合构造、交易执行等多个环节大量使用深度学习等模型。

**AI定位**：吕杰勇明确表示"**人机协同**是更优的资源配置模式"，强调"增量式创新"而非激进的范式替换。

### 2.4 自研系统——Bsim

公司自主研发的**Bsim系统**可实现**"分秒间即可验证一个因子想法"**的高效能，支撑研究员**日均完成上千次回测**。

2025年，公司算力资源**同比提升2.3倍**。


## 三、策略与产品线

### 3.1 策略频率与容量

**策略频率**：以**中低频为主**，换手率年化双边60-80倍，叠加T0策略后可提升至120-130倍。

**策略容量**：中低频策略天然具备**高容量（约200亿元）**，当前150亿规模仍处于**规模效应最佳阶段**。

**策略特点**：各产品线**独立策略**，而非同一策略套不同壳。

### 3.2 产品线布局

| **500指增** | 排名第5 | — |

### 3.3 产品体系

公司产品线主要包括：**指数增强（300/500/1000/2000指增）、市场中性、量化选股**等策略，存续产品数量**超过100只**。


## 四、风控体系

### 4.1 风控核心参数

根据公开信息，平方和投资的风控体系包含以下关键约束：

| 风控维度 | 控制标准 |
| :--- | :--- |
| **行业偏离** | ≤3%-5%（不同来源略有差异） |
| **风格暴露** | ≤0.5个标准差 |
| **个股持仓上限** | ≤1% |
| **微盘股暴露** | 严格控制 |

### 4.2 风控理念

平方和投资践行"**优势策略 + 严谨风控**"的双轮驱动模式。

**止损机制**：止损阈值**不是固定数字**，而是结合市场波动率、策略敞口**实时校准的"活参数"**。

**压力测试**：覆盖极端行情、流动性枯竭等黑天鹅场景，**连历史数据中未出现的"假设性危机"都纳入模拟**。

**容量管理**：始终将容量管理作为重要风控环节，做到容量和收益的黄金平衡。

### 4.3 风控流程

采用**事前、事中、事后全流程风控措施**，历史上**未出现重大风控事故**。


## 五、业绩表现

### 5.1 2025年业绩

截至2025年9月底，平方和投资旗下产品**平均收益达35.79%**，位列量化私募业绩榜**Top10**。

2025年度量化指增类产品行业平均收益超40%，市场中性类产品收益率普遍在10%以上。

### 5.2 历史业绩

- **2018年**：市场极度低迷，平方和投资仍交出**两位数的正收益**成绩单。
- **市场中性策略**：**实盘运行近10年，过往每一年都实现了正收益**。
- **全线产品**：各产品线历史业绩**全部为正**。

### 5.3 超额稳定性

平方和投资被业内评价为"**全线产品优秀，无短板，超额稳定年年正回报的管理人**"。


## 六、合规事件与风险提示

### 6.1 虚开发票事件（重大合规风险）

2025年8月，平方和投资因虚开发票被税务机关处罚。

**事件详情**：
- **时间**：2019-2020年生产经营期间
- **当事人**：总经理吕杰勇
- **行为**：为套取账面资金于账外使用，以支付**7%开票费**的形式收用虚开的增值税普通发票**173份**
- **金额**：价税合计**14,551,598.00元**（约1455万元）
- **名目**：多为"招聘服务费"等
- **处罚**：罚款**167万元**

**性质分析**：此事件属于**创始人个人行为**引发的公司治理层面问题，而非策略或产品层面的问题。但虚开发票套取资金的行为，暴露出公司在**内部控制、财务合规和治理结构**上存在严重漏洞。

### 6.2 行业层面的挑战

吕杰勇本人也坦承量化行业面临的三大挑战：
1. **策略同质化严重**，AI模型易陷入"拥挤交易"
2. **AI模型可解释性弱、过拟合风险高**
3. **极端行情下模型适应性不足**


## 七、总结与评价

### 7.3 对标思考：平方和投资 vs 幻方量化

平方和投资与幻方量化的差异，**本质上是一家"腰部优秀机构"与一家"行业规则制定者"之间的差距**。

#### 量级差距

| 维度 | 平方和投资 | 幻方量化 |
| :--- | :--- | :--- |
| **管理规模** | 约150亿元 | **超700亿元** |
| **行业梯队** | 100-200亿腰部区间 | **"四大天王"**之一 |
| **规模峰值** | 稳步增长中 | 2021年一度突破**千亿元** |

幻方的规模是平方和的**近5倍**，策略容量、IT投入和市场影响力完全不在一个量级。

#### 技术路线：AI工具 vs AI信仰

| 维度 | 平方和投资 | 幻方量化 |
| :--- | :--- | :--- |
| **AI定位** | 辅助工具（因子挖掘、模型优化） | **核心信仰** |
| **AI布局时间** | 近年逐步引入 | **2016年**深度学习模型上线实盘 |
| **算力投入** | 常规高性能服务器 | **"萤火二号"**AI训练平台 |
| **战略延伸** | 聚焦量化投资 | 孵化**DeepSeek**，进军AGI |

平方和把AI当作**提高预测精度的工具**；幻方把AI当作**公司的终极使命**——量化交易只是AI技术的第一个落地场景，AGI才是终点。

#### 合规污点对比

| 维度 | 平方和投资 | 幻方量化 |
| :--- | :--- | :--- |
| **合规争议** | **创始人虚开发票1455万**被罚167万 | **IT人员"老鼠仓"**1.77亿罚单；**市场总监"返佣门"**1.18亿 |

平方和的合规问题是创始人**个人行为**（公司治理层面）。幻方的问题涉及**IT人员利用内部未公开信息"抄作业"**和**市场总监伙同券商套取佣金**——这直接触及量化私募的**核心命脉：策略保密性和风控体系**。

### 7.4 对个人量化系统建设的参考价值

1. **因子均衡**：量价因子与基本面因子并重，而非偏科。机构资金量大必须配置基本面，个人可灵活调整。
2. **中低频策略**：7-10天预测周期，换手率适中，**对个人投资者高度可复制**。
3. **人工挖掘为主**：因子必须具有**可解释的金融逻辑**，而非纯黑箱。
4. **动态风控**：止损阈值不是固定数字，而是结合市场波动率实时校准的"活参数"。
5. **容量管理**：策略容量与收益的平衡，是规模扩张的核心约束。

**一句话总结**：平方和投资是一家**投研技术实力过硬、策略体系成熟、但公司治理存在重大瑕疵**的量化机构。其策略框架值得深入研究学习，但其合规风险也警示：**再好的策略，也抵不过人的问题**。对于个人量化，**平方和的"人机协同"路子比幻方的"AI一切"更务实、更可复制**。
