# c1skill 论证：at 权重 0.40 与 50 分钟更新周期

> 审阅目标: at 在融合中的角色定位、权重、更新频率
> 方法论: Stage 1 + Stage 2 + Stage 4

---

## Stage 1 — 声明与事实对照

### 声明 1: "at 是唯一的非价格信号源"

at 的输入数据：

```python
# from mind_tradingagent source code
data_sources = {
    "price": yfinance / akshare,           # OHLCV — 与 ly/ml 同源
    "news": EastMoney / Cninfo,            # 新闻 — 独有
    "fundamentals": akshare / tushare,     # 基本面 — 独有
    "sentiment": EastMoney 个股评级,       # 情绪 — 独有
    "global_macro": yfinance,              # 宏观 — 独有
}
```

| 数据源 | 是否非价格 | 更新频率 | 信息质量 |
|--------|----------|---------|---------|
| price (OHLCV) | ❌ 价格信号 | 实时 | 高 |
| news | ✅ **非价格** | 收盘后为主 | 🟡 ⚠️ |
| fundamentals | ✅ **非价格** | T+1 (财报季) | 🟡 |
| sentiment | ✅ **非价格** | 日频 | 🟡 |
| global macro | ✅ **非价格** | 日频 | 🟡 |

**结论**: at 确实有非价格信号源，但其质量受限于国内股市的信息发布特点。

### 声明 2: "50 分钟更新一次提供新鲜信号"

国内股市重大信息发布时间分布：

```
信息类型        发布时间              对50分钟周期的意义
────────────────────────────────────────────────────────
公司公告        15:00-20:00 (收盘后)    ❌ 盘中无新公告
政府政策        15:00-17:00 或盘前      ❌ 不在盘中
财报披露        收盘后                   ❌
行业数据        收盘后或早盘前            ❌
盘中异动        随时                    ✅ 但 at 的 LLM 分析延后 50 分钟
社交媒体        随时                    ✅ 但真假难辨
```

**结论**: 绝大部分非价格信号在**收盘后发布**。盘中 50 分钟更新的主要价值是**重新分析价格走势**，而非获取新新闻。而价格走势分析 ly 和 ml-factor 已经覆盖。

## Stage 2 — 代码级证据验证

### 2.1 at 的新闻源延迟

```python
# systems/mind_TradingAgent/mind_tradingagent/dataflows/y_finance.py
# → yfinance 数据延迟 ~15 分钟

# systems/mind_TradingAgent/mind_tradingagent/dataflows/akshare.py  
# → akshare 东方财富新闻源，非实时推送，需主动轮询
```

at 没有实时新闻推送通道，所有数据源都是**主动轮询**模式。50 分钟一次轮询相比 5 分钟一次，在新闻获取上没有差异——新闻不会因为轮询频率高就变得更及时。

### 2.2 at 的辩论流程耗时

```python
# 每只股票: TradingAgentsGraph.propagate() 
#   → 8-12 次 LLM 调用
#   → 3-5 分钟
# 10 只股票: 30-50 分钟
```

at 运行一次需要 30-50 分钟。这意味着：
- 即使新闻在 10:00 发布
- at 在 10:00 开始运行
- **11:00 才能出结果**
- 此时新闻已经发布 1 小时

**盘中运行 at 的"新鲜度"上限是 50 分钟**——任何在 at 运行期间发生的事件，要到下一轮才能反映。

## Stage 4 — 反方论据

### 4.1 "at=0.40" 可能被高估

| 支持 at 高权重的论点 | 反方论据 |
|-------------------|---------|
| at 提供非价格信号 | 国内新闻主要在收盘后发布，盘中非价格信号极度稀疏 |
| at 是唯一多样化来源 | 多样化价值依赖于源信息质量，如果新闻本身不可靠，多样化只是"多了一个错误来源" |
| at 的辩论过程降低幻觉 | 8-12 次 LLM 调用如果都基于同样的低质量新闻，集体幻觉风险仍在 |

**国内股市信息质量的几个现实问题**:

| 问题 | 影响 |
|------|------|
| 政策市为主，政策发布时间不透明 | at 无法提前获取政策信息 |
| 上市公司信息披露质量参差不齐 | at 基于的财务数据可能过时或不准确 |
| 盘中异动多由情绪/资金驱动 | 基本面和新闻分析对此无效 |
| 东方财富新闻源以转载为主 | 信息增量有限 |

**结论**: at 的非价格信号价值**低于理论最大值**，因为源信息质量受限。

### 4.2 "50 分钟更新周期"的意义需要重新评估

| 声称的优势 | 实际情况 |
|----------|---------|
| 获取最新新闻 | 新闻集中在收盘后，盘中 50 分钟周期没意义 |
| 跟踪价格变化 | at 用 yfinance 数据，但 ly + ml-factor 已经覆盖价格分析 |
| 跟踪基本面变化 | 基本面几天/几周才变一次，50 分钟没用 |

**at 盘中多次运行的真正价值**:

```
价值 1: 重新评估已有数据（辩论轮次越多越稳定）
  → 但同一批数据反复辩论的边际效益递减

价值 2: 捕捉价格形态变化（新 K 线形成）
  → 但 ly + ml-factor 已经做了这件事

价值 3: 风险重评估（若持仓有变化）
  → 这个有独立价值，但 10 只股票的持仓不会每 50 分钟变一次
```

**更合理的方案**: at 改为**每日 2-3 次**即可：

```
09:00 (盘前)   → 基于昨日收盘+隔夜新闻
13:00 (午盘后) → 基于上午走势+午间新闻
16:00 (收盘后) → 基于全天数据（当前已有）

盘中 50 分钟一次的边际价值很小。
```

### 4.3 修正建议

| 项目 | 原方案 | 建议修正 |
|------|--------|---------|
| at 权重 | 0.40 | **0.30**（非价格信号价值受限于源质量） |
| 日间运行次数 | 3-4 次 (每 50 分钟) | **2 次** (盘前+午盘) |
| at 的核心价值定位 | "非价格多样化信号" | **"多角度辩论共识"** — 不是信息源，而是分析方法 |

### 4.4 修正后的权重方案

```
ly=0.30   ml-factor=0.40   at=0.30

数学模型总权重: 70%
LLM 观点权重:   30%

at 的价值不在于数据新鲜度，而在于多角度分析方法的独特视角。
```

**与原始方案 (ly=0.35, ml-LLM=0.35, at=0.30) 的对比**:

```
原始: ly(RF,昨日) + ml(LLM报告) + at(昨日辩论) → 三个"昨日"系统
修正: ly(RF,昨日) + ml(因子,实时) + at(LLM,盘前午盘) → 时间分层
```

### 4.5 at 更新周期建议

```
盘前 09:00 — 基于:
  ├─ 昨日收盘技术面
  ├─ 隔夜新闻 (美股/商品/政策)
  └─ 当日重大事件日历
  → 输出: 当日初始评级

午盘 13:00 — 基于:
  ├─ 上午走势 (新增 2h K 线)
  ├─ 午间新闻 (11:30-13:00)
  └─ 上午发现的异动
  → 输出: 盘中更新评级

收盘 16:00 — 基于:
  ├─ 全天数据
  └─ 收盘后公告
  → 输出: 最终评级 (供明日使用)
```

这样 at 每日运行 3 次（含现有 16:00），比 50 分钟一次的方案节省 ~70% 的 LLM 调用量，同时覆盖了所有有意义的信息窗口。
