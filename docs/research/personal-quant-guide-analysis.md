# 个人量化交易全指南：从原理到实战，融合因子、策略、人性与AI

**版本**：3.0  
**适用对象**：拥有闲置资金（如50万）、希望系统化开展量化交易的个人投资者  
**核心理念**：用数学规则驾驭不确定性，用半自动化克服人性弱点，用LLM增强认知而非替代决策  

---

## 第一部分：量化交易基本原理

### 1.1 什么是量化交易？

量化交易是用数学模型代替主观判断，通过系统化的方式做交易决策。其核心流程包括：

1.  **数据获取**：历史价格、成交量、财务数据、新闻舆情等。
2.  **信号生成**：通过统计分析找出能带来超额收益的规律（因子）。
3.  **风险控制**：设定止损、仓位上限、最大回撤等规则。
4.  **交易执行**：按信号下单，可手动、半自动或全自动。

### 1.2 量化交易的核心优势

-   **纪律性**：克服贪婪与恐惧，严格执行规则。
-   **系统性**：同时分析成千上万只股票，捕捉分散机会。
-   **可回测**：用历史数据验证策略有效性，避免"拍脑袋"。
-   **概率思维**：不追求每笔都赢，追求长期正期望收益。

### 1.3 关键误区澄清

-   **胜率 ≠ 盈利能力**：一个胜率40%的策略，只要平均盈利/平均亏损 > 1.5，就能稳定赚钱。例如赚15%、亏5%，100次交易净收益 = 40×15% - 60×5% = 600% - 300% = 300%。
-   **止损 ≠ 割肉**：止损是策略失效时的保险，防止小亏变大亏。
-   **补仓 ≠ 摊低成本**：补仓意味着否定止损逻辑，将错误头寸加大，往往导致灾难。

## 第二部分：因子——量化策略的基石

### 2.1 什么是因子？

因子是能解释股票收益率差异的某种特征，比如估值、成长性、动量等。一个因子就是一个数学上客观的信号。

### 2.2 因子的分类

| 类别 | 典型因子 | 逻辑内核 |
| :--- | :--- | :--- |
| 估值类 | BP（账面市值比）、EP（盈利收益率） | 寻找被低估的资产 |
| 质量类 | ROE（净资产收益率）、毛利率稳定性 | 公司盈利的健康度 |
| 动量/反转 | 过去1个月收益率（反转）、6-12个月收益率（动量） | 价格趋势或过度反应修复 |
| 成长类 | 营收同比增速、盈余超预期 | 企业扩张能力 |
| 另类/流动性 | 换手率、机构持仓变化、情绪因子 | 微观结构与行为金融 |

### 2.3 因子的标准化处理（非常重要）

多个因子必须经过以下步骤才能合成：

1.  **去极值**：将极端值压缩到合理范围（如3倍标准差）。
2.  **中性化**：剔除行业和市值的影响，实现"行业内部优选"。
3.  **标准化**：转换为均值为0、标准差为1的数值，使不同因子可比。
4.  **离散化（可选）**：分成7档（-3到+3），提高稳健性。

### 2.4 多因子合成与动态权重

-   **为什么用多因子？** 单因子在特定行情下很准，但一旦失效会巨亏；多因子放弃极端收益，换取长期稳健（高夏普比率）。
-   **如何合成？** 加权求和。权重不应固定，而应根据因子近期表现动态调整。
-   **动态权重方法**：衰减ICIR加权——计算每个因子过去120天的信息系数（IC）与信息比率（IR），按时间衰减（近期权重大），归一化后作为下一期权重。这能自动适应市场风格切换。

## 第三部分：策略设计与回测

### 3.1 常见策略类型

| 策略类型 | 交易频率 | 适合个人？ | 原因 |
| :--- | :--- | :--- | :--- |
| 中低频多因子选股 | 周/月 | ✅ 最佳 | 数据易得，不拼速度，容量大 |
| 小市值增强 | 双周 | ✅ 推荐 | A股小市值效应显著，个人无冲击成本 |
| 事件驱动（财报、指数调仓） | 低频 | ✅ 适合 | 逻辑简单，机构难重仓 |
| 大类资产轮动（ETF） | 月/季 | ✅ 简单 | 交易品种少，可半自动 |
| 日内高频/套利 | 秒/分钟 | ❌ 不要碰 | 拼设备、网速、数据，个人必输 |

### 3.2 回测的核心指标

-   **年化收益率**
-   **最大回撤**（MDD）
-   **夏普比率**（收益/风险）
-   **胜率**与**盈亏比**
-   **最大连续亏损次数**（心理承受关键）

### 3.3 避免过拟合

-   **参数敏感性测试**：微小改变参数，结果不应剧烈波动。
-   **滚动窗口验证**：用前3年训练，后1年验证，逐年滑动。
-   **简化因子**：优先选20-30个逻辑坚实的因子，而非100个噪音。

## 第四部分：个人量化——现实与出路

### 4.1 个人的劣势与优势

| 劣势 | 优势 |
| :--- | :--- |
| 设备、网速不如机构 | 资金小，无冲击成本，进出灵活 |
| 数据有限（无高频、另类数据） | 可投资小市值、冷门股（机构无法重仓） |
| 无专业风控系统 | 无合规压力，可空仓等待 |
| 易受情绪干扰 | 策略容量无上限，可自由组合 |

### 4.2 推荐解决方案：半自动化量化系统

**为什么不全自动？**  
个人编写的全自动系统容易因代码错误、数据断连、API故障导致重大亏损。

**为什么不全手动？**  
手动容易受恐惧和贪婪影响，无法严格执行信号。

**半自动化工作流：**

1.  **系统生成信号**（每日收盘后）：运行多因子模型，输出次日交易清单。
2.  **自动推送**：通过钉钉/微信机器人发送到手机。
3.  **人工审核**（30秒）：检查大盘有无系统性风险、个股有无突发利空。
4.  **辅助执行**：使用券商QMT/PTrade的"篮子交易"功能一键下单。
5.  **系统同步**：导入成交记录，更新持仓。

### 4.3 执行纪律：对抗"执行落差"

-   **硬性时间**：信号触发后，次日上午9:45前必须完成交易。
-   **否决限制**：连续三次人工否决信号，暂停策略并强制复盘。
-   **执行率底线**：低于90%则该策略无效。

## 第五部分：人性弱点与交易心理学

### 5.1 常见弱点

-   **处置效应**：过早卖出盈利股，死拿亏损股。
-   **沉没成本谬误**：因为已经亏了，所以想补仓"捞回来"。
-   **锚定效应**：把买入价当参照，跌了觉得便宜，涨了觉得贵。
-   **损失厌恶**：亏损带来的痛苦远大于同等盈利的快乐，导致不敢止损。

### 5.2 为什么我们总想"补仓"？

因为大脑在进化中形成的本能：**避免承认错误**。补仓给人一种"我在主动控制局面"的错觉，实际上是在放大风险。量化系统必须用规则强行切断这种本能。

### 5.3 如何用系统克服弱点？

-   **规则化**：止损、仓位等全部写进代码，不留给情绪决策空间。
-   **可视化**：每天查看资金曲线和回撤，强化概率思维。
-   **小额试错**：先拿总资金1-5%实盘运行，亲身体验连续亏损但仍能盈利的过程，建立对系统的信任。

## 第六部分：LLM（大语言模型）在量化中的正确姿势

### 6.1 不可替代的领域（❌ 错误用法）

-   **替代执行层下单**：LLM数值敏感度低，存在幻觉，无法精确处理价格条件。
-   **作为黑盒信号源**：结果随机性强，无法复现，逻辑易崩塌。
-   **决定加仓/补仓/止损时机**：这是精确的数学规则，LLM不适合。

### 6.2 真正有价值的应用（✅ 正确用法）

| 应用 | 说明 | 个人落地方式 |
| :--- | :--- | :--- |
| **舆情情绪因子** | 解析财报、新闻、股吧评论，生成情绪评分 | 用免费API（如DeepSeek）批量处理文本 |
| **策略诊断** | 分析回测结果，指出可能的过拟合或逻辑缺陷 | 将回测报告输入LLM，要求输出改进建议 |
| **否决辅助** | 人工审核时，让LLM快速扫描个股是否有重大利空 | 输入股票代码，LLM返回近期争议事件摘要 |
| **因子挖掘启发** | 用自然语言生成新因子思路，再转化为代码验证 | "请列举3个与公司治理相关的潜在因子" |

### 6.3 接入原则

-   **数据匿名化**：去除股票代码、公司名，避免模型记忆未来数据。
-   **规则化提示词**：要求LLM输出结构化JSON（如`{"sentiment": -0.3, "reason": "..."}`）。
-   **保留最终决策权**：LLM仅作为参考，所有交易决策由规则代码或人工执行。

## 第七部分：从0到1的完整实施路线图（以50万资金为例）

### 阶段0：认知准备（第1周）
- [ ] 阅读本报告，理解"胜率≠盈利""止损是保险"等核心观点。
- [ ] 在模拟账户（如雪球、聚宽）手动模拟交易1个月，体会心理波动。

### 阶段1：基础框架搭建（第1-2个月）
- [ ] 选择数据源：Tushare Pro（免费500次/天）、Baostock（完全免费）、AkShare。
- [ ] 学习Python基础（Pandas、Numpy），熟练使用Jupyter Notebook。
- [ ] 搭建回测环境：Backtrader 或 VectorBT。
- [ ] 实现第一个简单策略：**EP + ROE + 低波动**，等权，月频调仓，回测3年。

### 阶段2：半自动化落地（第3个月）
- [ ] 开通券商QMT或PTrade（50万资产可免费开通）。
- [ ] 编写信号生成脚本（每日输出CSV）。
- [ ] 配置钉钉机器人自动推送信号。
- [ ] 手工执行1个月，记录每笔交易的实际滑点与执行延迟。

### 阶段3：风控与优化（第4-6个月）
- [ ] 实现动态权重（衰减ICIR）。
- [ ] 加入硬止损规则（单股亏损-7%自动提醒）。
- [ ] 接入LLM情绪因子（可选，先使用免费API，每日处理不超过100条新闻）。

### 阶段4：实盘小资金运行（第7个月起）
- [ ] 投入总资金的5%（2.5万元）实盘运行1个月。
- [ ] 对比回测曲线与实盘曲线，分析差异原因。
- [ ] 稳定后逐步加至20%（10万元），再运行3个月。

### 阶段5：持续迭代（长期）
- [ ] 每月生成业绩归因报告（各因子贡献度）。
- [ ] 每季度调整因子池，剔除失效因子，加入新因子。
- [ ] 每年进行一次完整的参数敏感性测试。

## 第八部分：核心结论——你必须牢记的10句话

1.  **量化不是预测未来，而是管理概率。**
2.  **胜率40%+盈亏比>1.5 = 优秀策略。**
3.  **止损是策略失效时的保险，不是割肉。**
4.  **永远不要补仓，除非你专门设计了左侧交易系统。**
5.  **个人做量化的最大优势是灵活，而非速度。**
6.  **半自动化是个人最佳实践，全自动风险高，全手动情绪重。**
7.  **多因子动态权重比固定权重更稳健。**
8.  **LLM是参谋，不是将军；用它读财报，别让它下单。**
9.  **从5%资金开始实盘，让真实亏损教育自己。**
10. **量化的最终目的不是赚钱，而是建立一套可重复、可优化的决策系统。**
