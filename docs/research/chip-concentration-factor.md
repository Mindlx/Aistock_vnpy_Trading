## 1. 核心发现

筹码集中度本身就是有效的横截面风险因子——不需要换手率配合。

### 1.1 最优切分点

通过网格搜索（7111 评估点）确定的集中度最优切分：

| 切分点 | 集中侧 avg_20d | 分散侧 avg_20d | **差** | 样本量 |
|:-----:|:-------------:|:--------------:|:-----:|:------:|
| **<8%** | **+2.10%** | **-3.50%** | **+5.61%** | 2525 |
| <12% | +1.50% | -3.67% | +5.17% | 2965 |
| <15% | +0.94% | -3.51% | +4.46% | 3431 |
| <20% | +0.30% | -3.06% | +3.37% | 4445 |

**8% 集中度是 20 日回报的最佳切分点**，集中侧 vs 分散侧回报差 **+5.61%**。

### 1.2 信号解释

```
集中度 < 8% (高度集中):
  → 筹码集中在少数持仓者手中
  → 主力锁仓 / 机构重仓
  → 市场下跌时抗跌 (avg -1% ~ +2%)
  → 市场上涨时弹性好

集中度 > 18% (较分散):
  → 筹码分布在散户手中
  → 无主力主导 / 博弈激烈
  → 市场下跌时跌幅放大 (avg -3% ~ -4%)
  → 无超额收益
```

### 1.3 因子属性

| 属性 | 值 |
|:-----|:---:|
| 因子名 | `concentration` |
| 显示名 | 筹码集中度(90%) |
| 类别 | quality |
| IC | **-0.1108** (p<0.0001, n=22943) |
| 权重 | 0.10 |
| 方向 | higher_better=False (conc越低=越集中=越好) |
| z-score 映射 | 8%→+2.0, 15%→0.0, 30%+→-2.0 |

### 1.4 与现有因子的相关性

| 因子 | Spearman ρ | p-value |
|:-----|:----------:|:-------:|
| 与所有 14 因子的 R² | **0.0006** | — |
| turnover_sentiment | -0.009 | 0.418 |
| momentum_reversal | -0.015 | 0.207 |
| size_factor | +0.009 | 0.416 |

**浓度因子是几乎完全独立的信息维度。**

### 3.1 时序归一化

集中度因子跳过时序归一化（无历史序列），使用线性映射直接计算 z-score：

```python
z = 2.0 * (0.15 - raw) / 0.15 if raw < 0.15 else -2.0 * (raw - 0.15) / 0.15
# 8% → +2.0, 15% → 0.0, 30%+ → -2.0
```
