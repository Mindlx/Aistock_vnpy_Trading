# 融合权重深度分析

> 讨论三个系统在时间维度、模型质量、信号独立性三个维度的权衡
> 日期: 2026-05-30

---

## 1. 三个系统在三维空间中的位置

```
                   信号独立性
                   (越低越独特)
                       ↑
                  at ●  (LLM辩论, 非价格信号)
                       |
                       |    ly ● (RF模型, 昨日数据)
                       |   ↙
                  ml-factor ●
                  (因子模型, 实时数据)
                       |
                       └──────────────────→ 数据新鲜度
                   stale             fresh
```

| 维度 | ly | ml-factor | at |
|------|----|-----------|----|
| **数据新鲜度** | 🟡 昨日收盘 (T+1) | 🟢 **实时** (有新K线) | 🟡 ~50分钟前 |
| **模型复杂度** | 🟢 **RandomForest** (15特征+集成) | 🟡 因子加权 (12因子线性) | 🟢 多智能体辩论 |
| **信号独立性** | 🟡 与ml同源(OHLCV) | 🟡 与ly同源(OHLCV) | 🟢 **独立**(非价格信号) |
| **幻觉风险** | 🟢 无 | 🟢 无 | 🔴 高 |
| **可回测性** | 🟢 完全可回测 | 🟢 完全可回测 | 🔴 低 |

---

## 2. 关键权衡：冗余 vs 多样化

### 2.1 ly 与 ml-factor 是部分冗余的

两者都使用 OHLCV 数据，都是数学模型。区别在于：

```
ly: 昨日数据 × 复杂模型 (RF 集成树)
ml-factor: 实时数据 × 简单模型 (因子线性加权)
```

如果两者高度相关（牛市中同时看多，熊市中同时看空），则权重加总过高会导致融合结果对 OHLCV 信号过度敏感。

### 2.2 at 是唯一非价格信号源

at 的多智能体辩论考虑了：
- 新闻情绪
- 基本面分析
- 市场分析师观点
- 风险管理

这些是 ly 和 ml-factor 完全无法覆盖的维度。**at 虽然主观且有幻觉风险，但提供了唯一的信息多样化**。

### 2.3 权重设计的本质矛盾

```
如果我们更看重  →  应该给更高权重
──────────────────────────────────
数据新鲜度     →  ml-factor
模型质量       →  ly
信息多样化     →  at
确定性/可回测   →  ly + ml-factor (合计占主导)
```

---

## 3. 权重方案对比

### 方案 A: 原提案 (数学模型 70%, LLM 30%)

```
ly=0.30  ml=0.40  at=0.30
```

| 优点 | 缺点 |
|------|------|
| 数学模型占主导 | ly+ml 相关性未被考虑 |
| ml 实时性体现充分 | at 的信息多样化价值被低估 |

### 方案 B: 基于 α 可靠度比例

```python
α_ly = 0.75, α_ml = 0.70, α_at = 0.40
总和 = 1.85

ly   = 0.75 / 1.85 = 0.405 → 0.40
ml   = 0.70 / 1.85 = 0.378 → 0.35
at   = 0.40 / 1.85 = 0.216 → 0.25
```

| 优点 | 缺点 |
|------|------|
| 基于系统本质可靠度 | at 权重过低 (25%) |
| 数学严谨 | 忽略了 at 的信息多样化价值 |

### 方案 C: 多样化优先 (数学模型 60%, LLM 40%)

考虑到 ly 与 ml-factor 的同源性，限制数学模型总权重 ≤ 60%：

```
ly=0.25  ml=0.35  at=0.40
```

| 优点 | 缺点 |
|------|------|
| ly+ml 总权重 0.60，避免过度集中 | at 权重 0.40 偏高 |
| at 的独特价值得到体现 | 幻觉风险暴露增加 |

### 方案 D: 时间衰减加权（推荐）

按数据新鲜度对 ly 做时间衰减，同时限制数学模型总权重：

```
核心公式:
  有效权重_ly = 0.25 × (1 - 衰减因子)
  衰减因子 = min(1.0, (当前时间 - 收盘时间) / 24h)
  
  交易日 15:30 (日终融合):
    衰减因子 ≈ 0 (刚收盘不久)
    ly_eff = 0.25, ml = 0.40, at = 0.35
  
  交易日 10:00 (盘中):
    衰减因子 ≈ 0.6 (已过 18h)
    ly_eff = 0.25 × 0.4 = 0.10
    归一化: ly=0.12, ml=0.47, at=0.41
```

但时间衰减过于复杂，且没有历史数据验证衰减曲线。

---

## 4. 推荐方案

综合考虑后，推荐 **方案 C** 为基础，小幅调整：

```
ly=0.25   ml-factor=0.35   at=0.40
```

### 理由

| 考虑因素 | 对权重的影响 |
|---------|------------|
| ly 与 ml 同源 OHLCV | ly 不宜过高 (0.25)，ml 作为实时版本略高 (0.35) |
| ml 因子模型比 ly 简单 | ml 不应超过 ly 太多 (0.35 vs 0.25) |
| at 是唯一非价格信号源 | at 应得到足够权重 (0.40) |
| at 有幻觉风险 | at 不应超过 0.40 |

### 三系统的角色再定义

```
ly=0.25:  昨日权威基线（复杂模型，但数据滞后）
ml=0.35:  今日实时修正（简单模型，但数据新鲜）
at=0.40:  独立观点输入（非价格信号，信息多样化）
           ↑ at 从"客观可信度最低"变为"信息多样化最高"
```

### 与旧权重的对比

```
旧 (全LLM层):   ly=0.35  ml(LLM)=0.35  at=0.30   → LLM 占 65%
新 (ml因子层):  ly=0.25  ml(因子)=0.35  at=0.40   → LLM 占 40%
                                                        ↓
                                              LLM 占比从 65% 降至 40%
                                              数学模型从 35% 升至 60%
```

这个权重方案将融合从"三个半主观系统投票"转变为"两个客观模型 + 一个独立观点"的架构，更符合三系统各自的本质。
