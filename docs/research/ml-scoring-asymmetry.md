## 一、架构全景

### 1.1 三层架构

```
层1: 14因子引擎 (FactorEngine) — 纯数学, 100%客观
层2: 18策略 (YAML Skill)       — 自然语言, LLM驱动, 不可独立运行
层3: LLM推理                   — 融合因子+策略+新闻+情绪 → sentiment_score + op_advice
```

### 1.2 各层可回测性

| 层 | 可独立回测？ | 方式 | 准确率 |
|:---|:-----------|:-----|:------|
| **1: 14因子** | ✅ 可独立 | `factor_backtest.py` | **50.1%** (接近随机) |
| **2: 18策略** | ❌ 不可独立 | 是LLM驱动的YAML文本, 非代码 | — |
| **3: LLM** | ✅ 有独立回测 | `c1test.py` Phase3 | **明确方向84.0%** / **全量62.2%** |

> **关键**: 因子独立50.1%接近随机, LLM在因子之上显著增值 (+26.4% 到 76.5%)。

## 二、真实问题定义

### 2.1 LLM 的问题不是"不会看多"

| 数据类型 | 看多准确率 | 看空准确率 | 说明 |
|:---------|:---------:|:---------:|:------|
| 明确方向(≥60/≤40) | **54.5%** | **66.7%** | LLM有表态时, 两个方向都可用 |
| 模糊区间(41-59) | — | — | 占 **50%** 样本, 准确率低 |
| **全量** | **~44%** | **~69%** | 被flat zone拖累 |

**LLM 不是不会看多——是太保守。** 50% 的时间输出中性分数(41-59)，这些中性样本的预测价值接近零。

### 2.2 真正的瓶颈

```
LLM 一次推理 → 三条信息挤在一个通道里:
  14因子(z-score) ──→ 文本表格 ──┐
  18策略(YAML)    ──→ 文本指令 ──┼→ LLM看/理解/推理 → 一个数字输出
  市场/新闻        ──→ 上下文本 ──┘
                                            ↑
                                    信息丢失: 数值变文本, LLM可能忽略或误读
```

**文档已明确标注的盲区**: `factor_zscores` 数值已被 `pipeline.py` 写入 `analysis_history.context_snapshot`，但融合层(`data_loader.py`) 未读取。因子信号经过 LLM 文本通道时精度丢失。

### 2.3 方向感知的正确认知

**ML 子系统内部 (非跨系统融合):**

| 场景 | 能力的来源 | 建议 |
|:-----|:----------|:-----|
| **看多** | 14因子(50.1%) + LLM(54.5%) | LLM明确看多时可用, 但需因子补充 |
| **看空** | LLM(66.7%) | LLM的看空可靠, 可独立使用 |
| **不确定** | 中性区间(41-59) 占50% | 应跳过, 不参与决策 |

## 三、待推进方向 (修正后)

### 方向A: factor_zscores 数值级融合 (优先级最高)

**问题**: 因子 z-score 以文本注入 LLM prompt → LLM可能忽略或误读

**解决方案**: `data_loader.py` 直接读取 `context_snapshot.factor_zscores`，以 L7 数值传给融合引擎。因子信号不再经过 LLM 文本瓶颈。

**改动范围**: `data_loader.py` + 融合引擎输入接口

**预期收益**: 因子信号保留完整数值精度

**工作量**: 1-2天

### 方向B: 策略级追踪数据链修复

**问题**: `analysis_history.skill_id` 已有 36 条数据, 但 `backtest_results` 0 条。修复 `67b029c` 完成了写入但未完成回测读取。

**解决方案**: 修复 `backtest_engine.py` → `backtest_repo.py` 数据链, 让 skill_id 传播到回测评估

**改动范围**: `backtest_engine.py`/`backtest_repo.py`

**预期收益**: 可评估18个策略各自的准确率 → 裁剪低效策略

**工作量**: 0.5天

### 方向C: LLM 表态率提升

**问题**: LLM 50% 时间输出中性分数(41-59)，这些样本的预测价值接近零

**解决方案**: prompt 优化 → 鼓励 LLM 在已有把握时输出方向性分数

**改动范围**: prompt 文本

**风险**: 可能降低明确方向的准确率(当前84.0%)
